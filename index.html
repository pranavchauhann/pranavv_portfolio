Video2Context — Screen Recordings for Coding Agents

A screen recording of a bug or UI feedback is the fastest way to explain a problem, but coding agents can't watch video. Video2Context (the v2c command) samples the recording in one FFmpeg pass, scores frame changes and perceptual hashes in NumPy to keep only the screens that actually changed, transcribes narration locally with faster-whisper, reads on-screen text with Tesseract, and fuses it all into a timestamped Markdown + JSON evidence package the agent reads alongside the screenshots. Local by default with no API keys; a doctor command checks the setup and a 2.5-minute macOS recording processes in about 9 seconds. Fixing frame seeking for variable-frame-rate QuickTime captures was the key correctness win.

GiftXpertise — Personalized Gifting Storefront

A storefront for personalized, handmade and curated gifts, built with Next.js 16 (App Router), React 19 and TypeScript on plain CSS, in a forest-green and antique-gold theme designed mobile-first. Shoppers filter the catalog through shareable URLs, customize a product with live pricing, photo-upload previews, engraving text, gift wrap and a delivery estimate, and approve a preview before a made-to-order piece is produced. A three-question Gift Finder builds a shortlist, a request form handles custom and bulk orders, and Blinkit / Zepto appear as separate quick-commerce channels for ready-made products.

  • Payments — Razorpay Standard Checkout with server-side pricing and HMAC signature checks; signed, de-duplicated webhooks, and a reconciler that asks Razorpay directly so a missed webhook heals itself. Cash on delivery only for ready-stock items.
  • Customer wallet — an append-only ledger with database-enforced idempotency keys: Razorpay top-ups, split wallet + gateway payments with holds released on expiry, store-credit refunds and a welcome credit.
  • Sign-in — phone + OTP with hashed codes, rate limits and httpOnly sessions; data in SQLite through Node's built-in driver.
  • Accessibility — focus states, ARIA labelling and reduced-motion support across the shop, customizer and checkout.

Status: in development, not yet live.

Indian Equity Price Forecasting — LSTM vs. Baselines

End-to-end ML pipeline forecasting next-day prices for 40 NSE stocks across 4 sectors, comparing LSTM against Naive, Linear Regression, and ARIMA with leakage-free chronological splits. Finding: LSTM matched simpler models on directional accuracy (~50% — a coin flip) while producing 3-4x higher price error, traced to output-scaler extrapolation failure on prices beyond the training range. Deployed as an interactive Streamlit dashboard.

Personal Ride-Data Analysis Dashboard

Analyzed my personal Uber ride export (47 trips, Sep 2024–Aug 2025): 70% of trips ran the same home→office route; a 36% cancellation rate traced to wait times (~10.8 min average ETA on canceled requests vs ~5.1 min on completed); surge-tagged trips cost ~8% more per mile once trip mix was controlled for.
